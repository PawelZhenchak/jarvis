# **App Name**: NovaChat

## Core Features:

- Chat Interface: Clean and modern chat interface for seamless communication.
- Chat History: Store chat history for continuity; remember, there is no backend so data is lost on browser close/refresh.
- User Avatars: Display distinct avatars/icons for users within the chat interface.
- Chat Summarization: Offer summaries of past conversations via a 'Summarize Chat' button, powered by a Large Language Model tool.
- Semantic Chat Search: Semantic search using LLM embedding of chats, allowing users to find chats or summarize them

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB), reflecting a sense of calmness and modernity.
- Background color: Very light blue (#E0F4FF), providing a clean and unobtrusive backdrop.
- Accent color: Soft lavender (#E6E6FA), complementing the blue tones for a harmonious feel.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable interface.
- Simple, outlined icons for actions and categories within the app.
- Use of whitespace to create a balanced, airy, modern design with distinct sections.
- Subtle, smooth transitions for chat bubbles and UI elements on interaction.
